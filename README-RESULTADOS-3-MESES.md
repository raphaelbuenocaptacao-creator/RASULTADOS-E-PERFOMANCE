# Resultados 3 Meses

Dashboard comercial com foco em VGV, casais, vendas, eficiência, ticket médio, ranking e evolução mês a mês.

## Acesso

Abra `resultados-3-meses.html` pelo GitHub Pages após ativar o Pages no repositório.

## Dados

O dashboard lê automaticamente `dados.csv` no mesmo repositório.
